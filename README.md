# ShainyDev

Portfolio site for ShainyDev — websites, apps, automation and AI by Shainy.

Built with Astro, TypeScript, Tailwind, GSAP (ScrollTrigger, SplitText) and Lenis. Deployed on Vercel.

```sh
npm install
npm run dev      # local dev server
npm run build    # production build into dist/
```

- All copy lives in `src/data/content.ts`.
- The public URL lives in `site.config.mjs`.
- Spec and tickets: `.scratch/portfolio-site/`.
